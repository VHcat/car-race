# COME ON! RACING · 来呀！赛车 v3

面向手机的俯视赛车游戏。左右拖动穿越车流，收集金币、补充燃油，用氮气撞开来车，或装备飞翼飞越障碍。纯 HTML / CSS / Canvas / JavaScript，无运行时依赖、无构建步骤。

## 开始游玩

- 直接打开 `index.html` 即可游玩。
- 本地启动：运行 `npm run serve`，打开 <http://localhost:4173>。
- 手机与电脑连接同一 Wi-Fi 时，可访问 `http://电脑的局域网IP:4173`（需系统允许局域网访问该端口）。
- HTTPS 或 localhost 下，首次完整加载后可离线游玩。支持的浏览器可在设置页安装；iPhone 可使用 Safari「分享 → 添加到主屏幕」。普通局域网 HTTP 仅支持在线游玩。
- 原有 GitHub Pages 地址为 <https://vhcat.github.io/car-race/>；本地提交不会自动更新线上版本。

## v3 的变化

保留原有 6 条赛道、10 辆赛车、车辆升级、7 种改装零件、飞翼、6 种道具、增益卡、转盘、签到、每日任务与成就。原 `carRaceSave` 存档自动迁移，保留金币、宝石、车辆、升级和已有纪录。

### 手机操作和画面

- 默认**相对拖动**：手指按下时车不会跳动，横向拖动控制转向；设置中可改为位置跟随。
- 一根手指转向，另一根手指长按 **NOS** 加速；装备飞翼后出现 **FLY** 按钮。
- 道具独立成行，支持 320px 小屏、横屏、刘海安全区和屏幕旋转。
- 全新维修站首页、动态赛车预览、六种赛道缩略图、检查站进度、局内挑战与事件提示。
- 路面纹理、路缘反光、来车预告、天气、夜间灯光和速度线；可选择流畅画质或减少动态效果。
- 切后台自动暂停并清除输入；复活倒计时也可暂停。

键盘：`A/D` 或 `←/→` 转向，`空格/W/↑` 氮气，`F/Shift` 飞翼，`1–6` 道具，`P/Esc` 暂停。

### 模式与路线事件

| 模式 | 目标 | 纪录 |
| --- | --- | --- |
| 无尽公路 | 管理燃油，尽量跑远 | 保留原赛道纪录 |
| 90 秒冲刺 | 在 90 秒有效比赛时间内跑远；撞车、没油仍会失败 | 独立赛道纪录，完赛额外 +100 金币 |

每局有三个一次性挑战：收集 25 金币、完成 5 次险胜、行驶 1500 米，分别奖励 40 / 60 / 80 金币。奖励计入本局结算。

赛道事件在约 650 米后开始轮换，每次提前 3 秒预告：

- **黄金路线**：沿指定车道连续收集金币，车流会预留该车道。
- **施工路段**：预告车道出现路障。普通碰撞扣 8 油量并减速；护盾可抵挡，氮气可撞开，飞翼可越过。
- **顺风路段**：极速提升 15%，缓慢补充氮气。

每 500 米检查站补充 8 油量并奖励金币。仪表盘和里程统一采用 km/h、米和秒换算；难度随里程逐渐提高。已装备的金币芯片、赛道倍率和双倍金币均参与金币收益计算。

### 稳定性修复

- 60 Hz 固定步长模拟，30 / 60 / 90 / 120 Hz 显示器保持一致游戏速度。
- 统一 Pointer Events、多指独立控制、取消触摸和失焦清理，限制横移速度避免瞬移穿车。
- 缩放时同步映射车辆、变道目标、金币、道具、冰面、路障及景物。
- 生成车流保留逃生车道；变道打灯 1 秒，执行前复查；小横屏限制来车逼近速度。
- 存档逐字段校验，不让无效索引、NaN、损坏嵌套字段或重复装备进入运行状态。
- 防止重复结算、重复签到、重复购买零件；转盘在揭晓前保存完整交易。
- 流畅模式使用 1× Canvas 像素比并限制粒子和天气数量；HUD 降频刷新。

## 代码结构

```text
index.html              页面和对话框
css/style.css           手机优先设计与响应式布局
js/data.js              车辆、赛道、零件、任务配置
js/save.js              存档校验、迁移与统计
js/runtime.js           固定步长时钟与布局坐标映射
js/main.js              输入控制与浏览器生命周期
js/game.js              比赛生命周期、碰撞、拾取与结算
js/abilities.js         燃油、氮气、飞翼资源系统
js/traffic.js           车流生成、变道与险胜
js/director.js          比赛模式、局内挑战与赛道事件
js/renderer.js          比赛 Canvas 渲染
js/menu-scene.js        首页赛车和赛道预览
js/car.js               程序化车辆绘制
js/ui.js                页面路由与养成系统
js/audio.js             WebAudio 合成音效和音乐
js/pwa.js               安装与离线资源状态
sw.js                   原子版本离线缓存
manifest.webmanifest    主屏幕安装配置
tools/serve.cjs          本地静态服务器
tests/                  Node 回归与 Playwright 浏览器验证
```

脚本使用明确顺序的传统 script 标签，保留 `file://` 直接运行能力。只有浏览器测试需要开发依赖。

## 验证

```sh
npm ci
npm test
npm run test:browser
```

浏览器测试默认使用 Windows 已安装的 Microsoft Edge。其他环境可设置 `BROWSER_PATH` 为 Chromium 浏览器路径，或运行 `npx playwright install chromium`。

覆盖：存档迁移与异常输入、固定步长、事件车道、变道可解性、5 种视口、真实多指触摸、飞翼耗尽、复活与结算、90 秒模拟、六种场景、后台暂停、养成交易、离线重载。截图写入忽略提交的 `artifacts/`。

浏览器自动化使用 Chromium 触屏模拟；iOS Safari 的系统手势、安装流程和真实设备性能仍需真机验证。

## 发布与存档

将根目录静态文件部署到 GitHub Pages 等静态服务即可，无需 `node_modules`、`tests`、`tools`。更新离线资源时递增 `sw.js` 的 `CACHE` 版本；新版本在旧页面全部关闭后启用，避免同一场比赛混用脚本版本。

进度保存在当前浏览器的 localStorage，不跨设备同步。`REFACTOR.md` 记录分阶段提交与验证结果。
